# 나를 소개하는 웹 페이지

Streamlit으로 만든 자기소개 페이지입니다. 이름, 소속, 꿈, 수업, 연구, 여행 정보는 `streamlit_app.py` 위쪽의 샘플 데이터를 원하는 내용으로 바꾸면 됩니다.

표지 사진 주소와 색상, 수업·연구·여행 항목도 같은 파일에서 수정할 수 있습니다.

## 실행 방법

필요한 패키지를 설치합니다.

```bash
python -m pip install -r requirements.txt
```

앱을 실행합니다.

```bash
python -m streamlit run streamlit_app.py
```
